## Access/reproducibility notes

Some Python urllib requests returned HTTP 403; ordinary curl requests with a browser User-Agent successfully retrieved the exact public images and the images were then opened. No login, paywall or access control was bypassed. The NOAA hosted 2022 Buck Island report download was unavailable, but the same NPS report was obtained from the NPSHistory mirror and its species/locality passages inspected with `pdftotext` (printed pp.23–24 and 120, DOI 10.36967/nrr-2293288). Facts are independently sourced from exact agency/species pages in the catalog. `fetch_references.py` preserves initial retrieval outcomes; later successful inspection is recorded here, not inferred from the fetch log.
