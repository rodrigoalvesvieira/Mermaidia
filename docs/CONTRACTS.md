# Integration contracts

`src/shared/contracts.ts` is coordinator-owned. World coordinates: meters, Three/glTF Y-up, Elise faces -Z at heading 0. Blender exports standard glTF axis conversion. Bounds rendered Y normally -12..0.5; surface at Y=0; deep educational meters separate in zones. Assets local `/assets/models/<assetId>.glb`; thumbnails `/assets/portraits/<id>.png`; fallback narration `/assets/audio/<id>.wav`. Preferred reviewed narration is requested through `/api/narration/<id>`; see [narration contracts](NARRATION.md) for generated-pack verification and the truthful fallback status. Biological models sized to actual meters with explicit rendering adjustments in discovery records. App may use entity scale for small-subject readability. Metadata must document it.

Content worker owns `content/catalog.ts` exporting `sources:SourceRecord[]`, `discoveries:DiscoveryRecord[]`, `habitats:HabitatDefinition[]`. At least six biological entries per destination, >=24 globally, and at least two non-animal features per destination. First entity must be within 4 m of first spawn, forward (-Z). All starts must be near some eligible subject. IDs shared with art worker. Agent may propose changes, not edit shared contracts.

Art worker owns scripts/blender, assets/source, public/assets/models and portraits, `assets/manifests/models.json`, docs/ART_DIRECTION.md. Assets named by DiscoveryRecord.assetId plus elise and terrain kit. Group node names for runtime animation: tail, fin_left, fin_right, hair, arm_left, arm_right, head when appropriate. Every scene uses actual GLBs.

Voice worker owns src/voice, src/audio, server/voice.ts, scripts/audio*, scripts/voice-live.ts, tests/voice*, docs/VOICE.md and audio manifest. Export registerVoiceRoutes(app:Express); VoiceController with start/stop and transcript callbacks; document exact API handoff. Coordinator handles server/index.ts. Commands shared above. Local parser returns `VoiceCommand[]`, `[]` for intentionally ignored/ambiguous speech, or `null` for unresolved navigation eligible for Astra; no action for negation/unrelated. The current [voice/audio API handoff](VOICE.md) documents command envelopes, activity callbacks, adult session renewal, narration echo suppression and mixer lifecycle. Preferred narration routes are registered separately by `registerNarrationRoutes(app)` from `server/narration.ts`. No dependencies installation by workers; request coordinator.
